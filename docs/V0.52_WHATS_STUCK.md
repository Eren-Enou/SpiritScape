# v0.52: What's stuck

**Player problem.** The Production tab opens with a card meant to answer one question: why isn't more being made? It was titled "What limits Planks", and only ever looked at Planks.

In the full-map scenario, Planks were at target and Structural Beams were stuck, because hauling couldn't bring Hardwood Logs fast enough. The Settlement summary said "Structural Beams stalled". The order list said why. Three spirits stood over the bench marked "waiting for materials". The headline card said:

> **None (target met)**. Planks target met: production has paused.

The one card titled to answer the question said nothing was wrong, at the top of the tab, in green.

**Now the headline follows whatever is actually stuck.** Nobody has played it.

## Design

- **The card is now "What's holding production up".**
- **When Planks are at target, or switched off, and another order is stalled,** it names that order in the warning colour, with the same sentence the order list gives: "Structural Beams stalled. Structural Beams waiting: hauling capacity is limiting Hardwood Logs delivery."
- **Otherwise it reads as before,** about Planks, which are the first and busiest chain.
- Only orders for a bench that exists count, as in the order list below it.

**What would count as failure:** the headline saying nothing is wrong while an order below it is stalled, or naming an order the player can't see.
