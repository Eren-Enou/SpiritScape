# v0.44: Left behind

**Player problem.** v0.39 lets you walk to the Far Shore in winter, but there was little to do when you got there. The old stones also tell of someone who gave everything away, and nothing of theirs was ever found.

**Now there are four things on the far shore for a person to find.** Nobody has played it.

## Design

### What was left

Four small cairns stand on the Far Shore, where no spirit would go. Walk up to one and you find what's there:

- **An axe head:** "It was sharpened by someone who knew how." It also teaches you 500 Woodcutting XP, which is worth a lot in a first winter.
- **A carving:** an unfinished figure. "It might be a helper. It might be a person."
- **A page:** "I asked one of them what it wanted. It asked me what wanted meant."
- **Four stones:** "It's the only thing here that wasn't made to be useful."

They go in your notes, and if you find all four, either ending says you carried them home.

Only the axe head changes anything in play. The rest are there because the person who cut the stones should have left more than instructions.

### A sixth reference style

The timeline in v0.42 showed the reference game's first caravan at 11:14. So there's now a style that sends one whenever it can afford to.

| | All goals | Hearth lit |
|---|---|---|
| Default | 16:57:25 | 13:40:37 |
| Sends caravans early | 16:08:58 | 12:33:37 |

That's about 48 minutes faster. It found no bugs, which is worth knowing, since this order of play opens the trades hours sooner.

It did need one change to the reference player: it no longer plans a building nobody can supply yet. Otherwise a Hearth planned with no Masonry Spirit sits at the front of the queue and holds up everything. A person can cancel a plan, so this doesn't trap anyone. That change also moved the default game a little, from 17:01:27 to 16:57:25, so earlier times aren't exactly comparable.

**What would count as failure:** a relic that can't be reached, or one found twice.

## The invisible spirits

The unpublished version of this milestone found that Quarrying, Masonry and Kiln Spirits had no body on the map. That fix was important enough to go into the release candidate (v0.40) instead, with its tests, so it isn't part of this change.

## Measured

- **The default reference game moved slightly:** all 19 goals by 16:57:25, from 17:01:27, for the reason above.
- **The reference player never crosses the ice,** but it finds the carving on its walk to the Shore Stone, once the South Crossing is built. The other three are only reached by tests.

## Validation

- `cargo test --workspace`: **615 pass**, 608 from before plus 7 new.
- Eight release-only long-run tests pass.
- `cargo clippy --workspace --all-targets -- -D warnings` is clean.
- **Thirty-nine UI scripts pass,** including new `ui_relics.txt`, which walks over the ice to the axe head.
- **One older UI script needed more slack.** `ui_production.txt` checked for the placing hint 0.1 seconds after clicking Place Workshop, and on this branch it failed about half the time. It passes every time when anything slows those steps down, including taking a screenshot, so it was a race in the script, not a broken button. It now waits 0.4 seconds, like its other steps, and passed eight runs in a row. Its expectations are unchanged.
- The save format stays at 9, because the new field defaults to empty.
- CI runs fmt, Clippy, the tests and the long runs on the PR.

## Not verified

- **Whether anyone goes looking.** The cairns are small, and nothing points to them.
- Whether the words land, or feel like too much.
