# v0.29: Learning As You Go

**Player problem.** After eight milestones of new systems, a new game opened with nine tabs and four skills before you'd cut a tree. The panel was a wall.

**A new game now opens with one skill and one tab.** Each of the other eight tabs and three skills appears when it first matters, with a line saying what it's for. Whether that teaches well is for a new player to say. Nobody has tried it.

## Design

- **Tips are data:** `[[tips]]`, each with a condition, a sentence, and optionally what it opens.
- **Conditions:** a journey phase, a finished building, a skill level, a season, or caravans sent.
- **Nothing is locked.** Tips only hide buttons. Every key still opens its tab, and everything works before the words appear.
- **Twelve tips,** from the Soul tab at the first spirit to Masonry at the third caravan, plus one for your first winter.
- **Real games only.** Scenarios show everything.
- **Older saves:** the first look only records what's already true, so nobody gets a burst of messages after loading.
- **Quieter panel:** the visitor's offer now appears inside What's Next, and takes no room when nobody's there.

**What would count as failure:** a tab that never opens, or a tip changing how the game runs.

## Measured

| At the start of a real game | v0.28 | v0.29 |
|---|---|---|
| Tabs shown | 9 | 1 |
| Skills shown | 4 | 1 |

A test confirms tips change nothing about how a game runs.

## Validation

- `cargo test --workspace`: **503 pass**, 494 from before plus 9 in `tests/tips.rs`. No existing assertion changed.
- Six release-only long-run tests pass.
- `cargo clippy --workspace --all-targets` is clean.
- All 27 UI scripts pass, including both real-game playthroughs. `ui_visitors.txt` now checks the quiet panel. I inspected a screenshot of a new game.
- The save format stays at 8.
- The repo has no CI, so all of this ran locally.

## Not verified

- Physical mouse and keyboard.
- **Whether a new player learns the game from this.** The only way to know is to watch someone.
- Whether tips arrive too fast at the end of the first cycle, when several open together.

## Human playtest

Best done by someone who's never seen the game, with you watching and not helping.

```bash
cargo run --release -- --new-game
```

- [ ] Where did they get stuck?
- [ ] Did they read the tips?
