# v0.33: Names

**Player problem.** Each spirit costs you real levels, and the game then named it for you. Traits were also pure luck, so there was nothing to think about when making one.

**You can now name your spirits, and you can see what the next one will be like.** Nobody has played it.

## Design

- **Naming:** a Rename button in Their Story (Spirits tab, `O`). While typing, the keyboard belongs to the name, so nothing else in the game reacts.
- **Up to 18 letters,** and spaces. Titles still follow: Old Pine the Road-Worn.
- **Traits now come round in order,** and the Soul tab shows the next one. If the next spirit will be Broad-backed, you might want to spend it on a hauling job, or wait.

### What changed about traits

They used to depend on the moment a spirit was made, so nobody could see one coming, and I'd rejected choosing them. Showing the next one keeps the character while giving you something to plan around. You still can't pick.

**What would count as failure:** typing a name moving the player, or a name breaking a save.

## Measured

The reference routes barely move: the Forest Crossing is at 2:19:38 and 2:17:16, because different spirits now carry the extra load.

## Validation

- `cargo test --workspace`: **518 pass**, 515 from before plus 3 new.
- **Two tests rewritten:** the trait tests relied on traits varying with time, and they now check the rotation. One test's expected capacity now allows for a trait.
- Six release-only long-run tests pass.
- `cargo clippy --workspace --all-targets` is clean.
- **Thirty-one UI scripts pass,** including new `ui_naming.txt`, which types a name.
- The save format stays at 9.
- The repo has no CI, so all of this ran locally.

## Not verified

- Physical keyboard. The script sends the same messages a keyboard does, but it hasn't been typed on for real.
- **Whether naming a spirit makes anyone care about it.**
