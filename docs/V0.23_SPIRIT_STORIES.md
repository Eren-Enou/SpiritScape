# v0.23: Spirit Stories

**Player problem.** Spirits were interchangeable. You gave up real levels to make one, and afterwards it was a name and a number. The game's central trade had nothing to remember it by.

**Each spirit you make now has a trait, a record of what it cost you, and a working life that builds up.** Whether that makes anyone care is exactly what a playtest would show. Nobody has played it.

## Design

- **Traits:** five, in data, given when a spirit awakens. Two carry more, and three are only character. You can't choose one.
- **Only spirits you make have a trait.** Founding spirits don't, so scenario results stand.
- **The making is remembered:** "Made at 1:41 from 16000 of your Woodworking XP."
- **Deeds:** six milestones, such as a thousand trips. The latest gives a title: Oakroot the Road-Worn. A playthrough gets a message for each.
- **Their Story:** a card at the top of the Spirits tab (`O`).
- **Names:** 24 instead of 8. Before, the ninth spirit was called "Spirit 9".

Deeds change nothing a spirit does, and a test confirms a world runs the same without them.

### Rejected

- **Choosing a trait:** it would turn a character into a build option.
- **Traits for work speed:** they'd touch every timing in the game, and would need balancing without a playtest.

**What would count as failure:** a deed changing the world, or traits being lost across a save.

## Measured

Reproduce with `cargo run -p spirit_sim --release --example guided_report`.

| | v0.22 | v0.23 |
|---|---|---|
| Forest Crossing, message-only player | 1:46:52 | 1:46:31 |
| All goals met | 12:00 | 12:07 |

These moved only because a spirit's trait can add to what it carries.

## Validation

- `cargo test --workspace`: **448 pass**, 436 from before plus 12 in `tests/stories.rs`. No existing assertion changed.
- Six release-only long-run tests pass.
- `cargo clippy --workspace --all-targets` is clean.
- **Twenty-two UI scripts pass,** including new `ui_stories.txt`. I inspected a screenshot of the card.
- The save format stays at 8. New fields have defaults, and spirits in older saves simply have no trait.
- The repo has no CI, so all of this ran locally.

## Not verified

- Physical mouse and keyboard.
- **Whether anyone cares about a spirit because of this.**
- The screenshot shows a founding spirit. I haven't seen a made spirit's card, though tests cover its text.

## Human playtest

```bash
cargo run --release -- --scenario quarry_start
```

Make a spirit from the Soul tab (`R`), then look at it in the Spirits tab (`O`).

- [ ] Did it feel like someone, or like a stat line?
- [ ] Would you have liked to name it yourself?
