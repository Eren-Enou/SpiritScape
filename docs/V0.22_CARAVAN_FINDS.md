# v0.22: What Caravans Bring Back

**Player problem.** A Trade Caravan gave room and nothing else, so sending one was only housekeeping.

**Caravans now open things you couldn't otherwise have.** The first brings Ironwood saplings, and the second a mason's survey. Each one lets you plan a building that adds real trees or outcrops to the map. Nobody has played it.

## Design

- **Finds are data:** a building with `needs_caravans` stays off the plan until that many have gone. `caravan_find` is what the player is told.
- **`plants`:** a building can add trees or outcrops to the map when it's finished. They're ordinary and regrow like any other. A tile built on since is skipped.
- **Ironwood Nursery** (first caravan): three Ironwood trees in the Starting Grove.
- **Quarry Extension** (second caravan): three more Stone Outcrops.
- **New goal:** Grow Ironwood near home, making 14 in all.

More finds can be added with no code, which later milestones will use.

**What would count as failure:** finds making no measurable difference, or a goal that can't be met.

## Measured

Reproduce with `cargo run -p spirit_sim --release --example quarry_report`. Thirty minutes of steady running, with gatherers free to work anywhere:

| Settlement | Hardwood/min | Beams home/min |
|---|---|---|
| Expanded, central | 15.0 | 8.2 |
| With the nursery | 18.1 | 9.4 |

Spirits **posted to Old Growth don't use the nursery.** My first measurement showed no change at all for this reason. A player has to take that instruction off to benefit, and I don't know if they'd realise.

One long game, from `all_goals_report`:

| | v0.21 | v0.22 |
|---|---|---|
| All goals met | 12:55 | 12:00 |
| Left behind | 2,240 | 476 |

Ironwood near home gives the player better XP on a short walk, which is why Woodcutting 20 comes sooner and less is thrown away. The reference player now plans what a goal needs before it can pay for it. That also changed this result.

The first run with this version missed the nursery goal, because the reference player waited to afford it while panels kept using the planks. Planning first lets demand do its job, which a person may also need to discover.
