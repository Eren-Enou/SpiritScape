# v0.45: Settings

**Player problem.** Sound was on or off, and text had one size. That's fine for ten minutes, but in a 20-hour game the sounds can wear on you, and small text on a big screen is tiring.

**You can now set how loud the game is and how big its text is.** Nobody has played it.

## Design

- **Sound:** 100%, 75%, 50% or 25%, in the Menu. `M` still mutes it.
- **Text:** 100%, 115% or 130%, in the Menu. It scales all the panels, not just the words, so everything stays in proportion.
- **They're kept in `settings.txt`, beside your saves,** so they survive a new game. They belong to you, not to a game.
- **A damaged settings file can never stop the game.** Anything it can't read falls back to the default, one setting at a time.

### What had to change with the text size

The panels get bigger, so everything that knows how big they are had to change too: where the map stops taking clicks, where the mouse wheel scrolls the panel instead of zooming, how the camera keeps you centred in the part of the map you can see, and where name labels and tooltips are drawn.

**What would count as failure:** clicks landing in the wrong place at a larger size, or a setting that doesn't stick.

## Bugs this found

- **Name labels drifted off their objects at larger sizes.** Every check passed. Only the screenshot showed "You" floating away from the knight. Labels are placed in screen pixels, and the UI scale was multiplying those too.
- **The script tool clicked in the wrong place** at larger sizes, for the same kind of reason. That was the tool, not the game.

## Already in the release candidate

The unpublished version also stopped the game naming Clay Bank before there was any clay. That went into the release candidate (v0.40), with its test, so it isn't part of this change.

## Measured

The settings don't touch the simulation, so the reference games are unchanged.

## Validation

- `cargo test --workspace`: **621 pass**, 615 from before plus 6 new.
- Eight release-only long-run tests pass.
- `cargo clippy --workspace --all-targets -- -D warnings` is clean.
- **Forty UI scripts pass,** including new `ui_settings.txt`.
- `ui_settings.txt` now waits 0.8 seconds after its last screenshot before exiting. At 0.2 seconds, the large-text screenshot was sometimes never written, so nobody could look at it. I've now inspected it: labels sit over their objects at 130%.
- The save format stays at 9, and settings are in their own file.
- CI runs fmt, Clippy, the tests and the long runs on the PR.

## Not verified

- **How any sound level actually sounds.** I can't hear it.
- Clicking the map at 130% with a real mouse. Scripts press buttons at that size, but they don't click the map at it.
- Whether 130% is big enough on a large screen.
