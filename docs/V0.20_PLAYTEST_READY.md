# v0.20: Ready to Play

**Problem.** Eleven unplayed versions are stacked up, each with its own checklist, and frame rate had never been measured.

**This version makes a playtest easy.** There's one hour-long guide in [PLAYTEST.md](PLAYTEST.md), a `full_map` scenario with everything built, and a `--fps` flag. It adds nothing to the game itself.

## Frame rate

`--fps` logs the rate every five seconds. On this machine, in the 1600x920 window:

| Scene | Frames a second | Slowest frame after loading |
|---|---|---|
| `full_map`, overview, 8x speed | 60 | 18.7 ms |
| `plank_surplus`, close up | 60 | 17.6 ms |

- **It's capped at 60 by vertical sync,** so this shows there's headroom on this machine, not how much.
- **The first five seconds show a 250 ms frame,** from loading.
- **This is one machine.** I don't know its result on a weaker one.

## Validation

- `cargo test --workspace`: **421 pass**. No assertion changed.

- **Twenty UI scripts pass,** including new `ui_full_map.txt`. I inspected a screenshot of the full map.
