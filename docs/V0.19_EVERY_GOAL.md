# v0.19: Every Goal

**Question.** Can all twelve long-term goals actually be met? No test had reached the level 20 ones.

**Yes, but it exposed the game's real limit: nothing uses goods without end.** The first long run stalled for 60 game hours with Main Storage full, and neither level 20 goal was met. All twelve can now be met in one game, but the last one relies on throwing away 6,160 units of goods. That's a design gap I've patched around, not solved, and it needs your view.

## What the long run found

`play_all_goals` carries on from the guided route: it cuts stone, makes panels when planks are plentiful, buys what the goals name, then trains both wood skills to the top.

| Run | Result |
|---|---|
| First | Stuck for good: 979 panels filled Main Storage. Neither level 20 goal met after 60 hours |
| Six Warehouses instead of two | Woodworking 20 at 8:11, then stuck: 1,029 logs and 1,150 panels filled 2,550 room |
| With "Leave your load" | All twelve met by 12:55:39 |

## The changes

- **Panelled Warehouse:** up to six instead of two.
- **Leave your load:** a last resort. When Main Storage won't take anything in your bag, a button appears under it, and the storage message offers it last. The goods are gone for good, and the ledger records them. It's refused while there's anywhere to put them.
- **`no_room_left` scenario:** Main Storage completely full.

This reverses a line in my backlog: "not a disposal button". That was about planks having no use. Planks have uses now, so this is only for a store that takes nothing. It's easy to remove if you dislike it, but then Woodcutting 20 can't be reached.

## Measured

Reproduce with `cargo run -p spirit_sim --release --example all_goals_report`. This player never hesitates, so a person will take far longer.

| Goal | Met |
|---|---|
| First seven goals | by 2:28 |
| Open the quarry | 2:36 |
| Bridge the river in stone | 2:37 |
| Build a Panelled Warehouse | 2:58 |
| Master Woodworking | 8:11 |
| Master Woodcutting | 12:55 |

The run ends with Main Storage at 2,550 of 2,550 and 6,160 units left behind.

## What this means

- **There's no ongoing use for goods.** Everything that spends them is a one-off. Past a point, gathering is only for XP.
- **Options for a real fix:** something that uses goods repeatedly, such as road upkeep or a goal that consumes stock. I don't want to pick one before anyone has played, because whether it's a problem depends on whether people ever reach this point.

## Validation

- `cargo test --workspace`: **421 pass**, 418 from before plus 3 new. No existing assertion changed.

- `cargo clippy --workspace --all-targets` is clean.
- **Nineteen UI scripts pass,** including new `ui_no_room.txt`. I inspected a screenshot of the button.
- The save format stays at 8, because the new ledger field has a default.
- The repo has no CI, so all of this ran locally.
